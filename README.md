# Eltex TW

Frontend build setup powered by Gulp. Source files live in `#src`, and the build output is written to `dist`.

## Installation

1. Install Node.js (LTS recommended).
2. Install dependencies:
   ```
   npm install
   ```

## Development

Start the dev server with live reload:
```
npm run dev
```

## Build

Create a production build:
```
npm run build
```

## Other Commands

Clean the build output:
```
npm run clean
```
